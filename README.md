# Projet-pdf-compar
application de comparaison de pdf

Le problème : Automatiser les tests de comparaisons PDF lors des TNRS 

La cible : Développeurs dans l'éditique ?

La proposition de valeur : L'automatisation des tâches et réduire le niveau d’interprétation humaine

Découpage du projet:

1-Comparaison des fichiers PDF Poids Nombre de pages, Metadata
2-Comparaison Textuelle des PDF
3-Comparaison Image/Pixel des PDF
4-Generer un rapport
5-Configuration des comparaisons
